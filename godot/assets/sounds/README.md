# Sounds

Drop files here named after the hook (`.ogg`, `.wav` or `.mp3`); missing ones are silent. The s&box sounds were
Facepunch cloud assets, so none ship with the port.

| Name | When |
| --- | --- |
| `rifle_shoot`, `shotgun_shoot` | a shot (the weapon's ModelName + `_shoot`) |
| `mag_out`, `mag_in` | reload start and finish |
| `dry_fire` | trigger with an empty gun and no reserve |
| `hit_world`, `hit_flesh` | bullet impacts |
| `axe_swing` | melee swing |
| `jump`, `land` | player movement |
| `hurt`, `death` | player damage and death |
| `splat` | gore (GoreSystem.Squelch) |
| `wave_start`, `wave_cleared` | wave banners |
| `buy`, `deny` | buy stations |
